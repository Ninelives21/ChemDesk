# ChemDesk refined starter

A quieter, more trustworthy ChemDesk starter with tasteful academic colours and fewer explanatory boxes.

## Structure

- `index.html`
- `assets/css/tokens.css` — palette, spacing, radii, shadows
- `assets/css/reset.css`
- `assets/css/base.css`
- `assets/css/layout.css`
- `assets/css/components.css`
- `assets/css/utilities.css`
- `assets/css/main.css`
- `assets/js/app.js`

## Direction

- No large marketing tagline
- Exam cards first
- Minimal explanation
- Warm academic background
- Restrained colours: deep blue, teal, sage, clay, plum, gold
- Components for MathJax, tables, PYQs, lecture source maps, accordions and nested accordions
