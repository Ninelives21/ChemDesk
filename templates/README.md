# ChemDesk Authoring Templates

This folder contains reusable templates for adding or reviewing ChemDesk content structure.

These templates are not student-facing content.

Use these when manually adding future chapters, lectures, or replacement-source lecture scaffolds.

---

## Core rules

- Stable IDs must remain clean and unprefixed.
- Folder prefixes are only for human ordering.
- Metadata is the source of truth.
- `data/content-registry.json` is generated; do not edit it manually.
- Public/RAG-ready content must only use approved/published material.
- Do not mark content as `approved` or `published` without review.

---
