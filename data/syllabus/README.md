# ChemDesk Syllabus Maps

This folder stores syllabus-based mapping files.

ChemDesk supports two navigation models:

1. Lecture-based navigation  
   `content/<category>/<chapter>/lectures/<lecture>/`

2. Syllabus-based navigation  
   `exam → syllabus unit → chapter/concept/note`

The lecture-based scaffold already exists under `content/`.

This folder is for the second model.

---

## Current status

These files are placeholders.

They do not yet contain complete syllabus mappings.

Do not use these files for public navigation, public search filters, or RAG until mappings are reviewed.
